This product contains code compiled against headers from the Blackmagic Design
DeckLink SDK:

  _internal\decklink_monitor.dll    Read-only signal status monitor, compiled
                                    from decklink_monitor.c against the SDK's
                                    DeckLinkAPI.h and DeckLinkAPI_i.c. It uses
                                    IDeckLinkStatus only, takes no exclusive
                                    device lock, and ships inside the
                                    application itself -- in EVERY build of this

                                    only in builds that include the filter
                                    chain.
