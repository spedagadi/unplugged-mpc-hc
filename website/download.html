What's new in 2.1.0

  • NLS is set-and-forget. Auto handles clean 16:9 and scope content as well as letterboxed sources. Bars removed controls every fill mode, and Max distortion caps the warp.
  • Post-NLS X and Y crop. Trim each axis after stretching — the whole frame, including bars, in real time.
  • Clean scope-to-IMAX transitions. Bands are tracked per frame instead of a stale crop. One IMAX frame can still use aspect-ratio NLS during a transition.
  • A reliable library. Season, episode and movie rows with posters, plot, facts and IMDb chips; ratings always shown; all episode thumbnails; a Wikipedia fallback and a 900-a-day OMDb budget.
  • One-click diagnostics. Report a problem now bundles a diagnostics zip.
  • Upgrade in place. 2.1.0 installs over 2.0.0 and keeps your library, presets and calibration.

Before you install

  • Windows 10 or 11, 64-bit. Tested on an RTX 4070.
  • A Blackmagic DeckLink card for live HDMI. DeckLink Quad PCIe and Mini Recorder 4K are confirmed; movie playback needs no card.
  • Blackmagic Desktop Video runtime. Install the latest drivers from Blackmagic's support portal before processor mode. Unplugged does not bundle them.
  • An unencrypted HDMI signal. DeckLink inputs do not accept HDCP-encrypted sources, and Unplugged does not decrypt or bypass HDCP.
  • The Microsoft Visual C++ 2015–2022 x64 runtime. The installer carries it and installs it silently when it is missing, so this is not something you need to fetch first.
  • Administrator rights. Double-clicking the installer raises the Windows consent prompt. On a machine where elevation is impossible, right-click and choose Run as administrator instead of failing halfway.
Upgrading from 1.2.0 or earlier: uninstall the previous version first (Windows Settings → Apps → Unplugged). 2.0.0 is a different application; installing over the old one leaves its Python files behind. Your settings are kept by the uninstaller.
Content protection: Unplugged does not decrypt, strip or bypass HDCP or any other content protection. It works only with unencrypted HDMI and content you are authorized to access. Commercial disc and streaming content is typically protected and is not supported. Read the content protection policy.

Install

  1. Install Blackmagic's Desktop Video runtime. Download it from Blackmagic's support portal if it is not already installed. It is required for live HDMI and is not bundled with Unplugged.
  2. Run the installer. Two licence pages are mandatory: the Blackmagic DeckLink SDK licence and Unplugged's own end-user terms. Third-party licences ship in the installed product's licenses folder.
  3. Choose Video Processor or Media Player. Video Processor lists every port on your DeckLink card with its live signal state, lets you name each one and pick the active input. Media Player skips straight to your library.
  4. Set the display target once. SDR display nits, static nits and display black come from a measurement of your screen. They describe the display, not the film, and they are the numbers the tone curve maps into.
  5. Start watching. Settings reach the picture as you change them, including on a paused frame.

What first run gives you

  • Five ready presets. On an upgrade, your existing picture is copied into five presets and Preset 1 is made active, so the picture looks exactly as it did and your tuning continues there.
  • A read-only Default. Picture changes while Default is active are refused rather than silently applied.
  • Presets that save themselves. No Apply button. Clicking a preset switches immediately and keeps the card open so you can compare setups on one frame.
  • Settings that survive reinstall. A re-install never costs you a tuned grade. The setup wizard returning after an install is the only thing that resets.

Known limitations, stated plainly

  • Windows today.
  • HDCP-encrypted HDMI is not supported. Unplugged does not decrypt or bypass it; use sources you are authorized to capture.
  • No ISO or BDMV folder/playlist playback. Rip to a file first.
  • Dolby Vision in files (profile 5) is not supported in media player mode. Dolby Vision over HDMI is recognised and handled.
  • During a scope-to-IMAX transition, one IMAX frame can still use aspect-ratio NLS.
  • Subtitle styling applies to text tracks. Bitmap tracks arrive pre-rendered.
  • Strong non-linear stretch can soften fine text. Both axes are being resampled; lower the strength or raise centre protection.
  • A calibration LUT describes one display. Moving the PC to another panel means another measurement.

The application is GPL-3.0. The binaries in the installer are built from four public repositories:
