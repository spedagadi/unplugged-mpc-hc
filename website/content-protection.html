unplugged/Content protection

HDCP and DRM

Content protection, stated plainly.

Unplugged is a video processor and media player, not a DRM circumvention tool.

The short version: Unplugged does not decrypt, strip or bypass HDCP or any other content protection. It works only with unencrypted HDMI signals the source already provides, and with content you are authorized to access.

What Unplugged does

  • Processes an unencrypted HDMI signal. A DeckLink input receives the signal, and Unplugged applies tone mapping, the Zion Grade and calibration to it.
  • Plays files you already have. The media player decodes local MKV, MP4 and similar files with the same picture pipeline.
  • Leaves content protection alone. It handles the signal as the source provides it. It does not negotiate, remove or alter content protection.

What it does not do

  • It does not decrypt or strip HDCP. There is no bypass, no decryption key and no “remove HDCP” feature.
  • It does not remove DRM from files. It plays files that are already playable; it is not a decryption or ripping tool.
  • It does not play commercial disc images. ISO and BDMV folder/playlist playback are not supported.
  • It does not support protected commercial content. Commercial disc and streaming content is typically HDCP-protected and will not pass through a DeckLink input.

What that means for your setup

The HDMI source must already output an unencrypted signal. Sources that enforce HDCP will show no picture. That is a property of the input path and of the source, not something Unplugged can or will change.

Use content you are authorized to access. Typical examples are your own camera output, a PC desktop or application, a game capture path where the platform permits it, and home video you own. The media player is for files you already have the right to play.

If a source shows no picture

The most likely cause is an HDCP-protected source. Unplugged cannot help bypass it, and support cannot provide instructions for doing so. Choose an unencrypted source, or use the media player for a file you already own.

Why the limitation exists

Blackmagic DeckLink inputs accept unencrypted HDMI only. Unplugged is built on that input path and does not add circumvention around it. Respecting content protection is a product requirement, not a missing feature.
