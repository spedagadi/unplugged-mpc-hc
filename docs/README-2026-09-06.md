## 1. LAV Filters: registration + DeckLink FFmpeg

**Pointers:** `C:\Code\LAVFilters\bin_x64\` · `C:\Code\LAVFilters\build_ffmpeg.sh`

- **Problem:** built LAV, but the `.ax` objects wouldn't register (error 126 /
  silent fail).
  - **Cause:** the FFmpeg DLLs still imported `zlib1.dll` + `libwinpthread-1.dll`
    at load time; they weren't in `bin_x64`.
  - **Fix:** copied the two sidecars from `C:\msys64\ucrt64\bin`. Registration
    then succeeded; decode was **user-verified in MPC-HC**.
  - **Open:** statically linking those two (fully sidecar-free) is deferred.
- **DeckLink FFmpeg flags** — three issues, each surfaced by configure/link:
  - `--enable-avdevice --enable-decklink --enable-indev=decklink` requires
    `--enable-nonfree`.
  - Decklink `.cpp` wants its own headers → `--extra-cxxflags -Idecklink`
    (CXXFLAGS is separate from `-I...` in CFLAGS).
  - `avdevice` pulled `libstdc++-6.dll` → `-static-libstdc++`.

`bin\mpc-hc_x64 Lite\mpc-hc64.exe` (Release Lite x64) loads the registered LAV +

## 3. Architecture decisions (locked)

1. **Form factor B** — one window; panels **overlay** the video (video never
   resizes), not a parallel shell.
2. **Engine = mpc-hc in place** — don't reinvent mpc-hc's frame→renderer
   machinery. The thin `mpchc_engine` seam (`MpcPlayer`) **selectively lifts**
   renderer plumbing, not `FGManager` (which drags `MainFrm.h`/`mplayerc.h`/
   `SyncAllocatorPresenter.h` — recorded in S0).
3. **LIVE left, settings right** — right rail = **Playback | System** tabs;
   System is a **hierarchical icon rail** (SOURCE/HDR/ZION/OUTPUT/SYSTEM) with
   sub-categories, Unplugged-style.
4. **Zion ML rules** — preload every model regardless of usage (never
   load/unload mid-play); **no settings persistence** (demo = test mode);
   paused frames must re-grade.
5. **Scope cuts** — no recording, no network surfaces, no disc menus
   (API-reserved).

## 4. The S1 "black screen" saga → engine seam (S2)

- **S0 proven:** open→play→seek through registered filters with a thin DShow
  controller.
- **Blocker:** a standalone spike built a valid graph, hosted MPCVR, still
  showed **black**. Two independent causes:
  1. Old test clip `test30.mp4` (mpeg4 testsrc) is white/black even in known-good
     MPC-HC — a red herring; replaced with H.264 SMPTE bars
     `tools/engine_spike/test30_h264.mp4`.
  2. MPC-HC drives MPCVR via `CLSID_MPCVRAllocatorPresenter`
     (COM-aggregation + `ISubRender`/`ISubRender11` + `IExFilterConfig` flags
     `lessRedraws`/`d3dFullscreenControl`). That CLSID is **not registered COM**
     — it lives in-process in mpc-hc. The spike's `CoCreateInstance` failed
     `0x80040154` and fell back to plain MPCVR, missing the setup contract.
- **Resolution:** build the engine seam instead of retro-fitting the spike.
  `MpcPlayer::{Open,Play,Pause,Stop,Seek,ResizeVideo}` + `AttachRenderTarget(HWND)`
  + `SetRenderer(MPCVR)` → **visible video, user-verified** on the SMPTE bars +
  `Exodus.mp4` (`tools/engine_s2/s2_driver.exe --renderer mpcvr <file>`).

## 5. S3 shell — functional inventory

One window; video fills the client; three overlay panels (left LIVE / right
rail / bottom bar). **Up** toggles WATCH ⇄ EDIT (panels shown/hidden).
`s3_shell.cpp` is the entire UI — no vcxproj; built by `build_s3_shell.bat`
(`cl.exe` + `mpchc_engine.lib`).

| Area | What it does | How it was built |
|---|---|---|
| Window/layout | Frameless maximized, per-monitor DPI (`GetDpiForSystem`, `S()` scale), Inter fonts loaded PRIVATE from `C:\Code\unplugged\brand\fonts\` | Dropped `WS_EX_LAYERED` (wiped icons over D3D) → opaque panels; double-buffered paint (kills flicker); hover repaints throttled by a coarse `HoverToken` |
| Left LIVE pane | Header + PERFORMANCE (state/position/duration), VIDEO SOURCE, CAPTURE INPUT (S4 placeholders), ZION ML internals polled every 500 ms | GDI `PaintSection`/`PaintRow`; live MPCVR internals via `GetMlStats` + `GetMlSettings` |
| Right rail | Playback ⇄ System tabs; System = icon rail (SOURCE/HDR/ZION/OUTPUT/SYSTEM) → category chip → rows | Row engine of exactly three types **toggle · cycle · slider**; icon rail made snug per user request |
| Row model | ~45 settings rows with **exact MPCVR dialog domains** (gamma 0.5–1.5, chroma ties, HDR nits, texture formats …) | `BuildRows()` mirrors MPCVR's PropPage inventory; keys `zion.* / hdr.* / out.* / sys.*` |
| Gating | Enable-master lock → group-Off lock → per-control checkbox; sliders snap to defaults unless **Manual** | Split `disabled` (hard lock) vs `adjustable` (Manual-only drag) — fixed "everything grey / can't toggle" |
| Mode rows | Tone **Auto/Manual/Off**, Chroma **Default/Manual/Off**, Detail **Auto/Manual/Off** (Recovery→Detail, disable→Off renames) | `BuildMlFromRows()` maps rows → `MlSettings`; MPCVR's single `iMLMode` driven by the Tone section |
| Bridges | Every change live-applies: rows → `SetMlSettings`/`SetHdrSettings`/`SetOutSettings`; renderer → rows on pull | `Push*/Pull*` per group; "applied: <key>" line in-panel |
| Paused-frame edits | ML toggle / structural changes re-render the still | MPCVR re-processes current sample on `SetSettings` while paused + a same-position seek nudge |
| Playback sheet | STREAMS list (V/A/S tracks), AUDIO DEVICE list, HARDWARE row | Track clicks → `SetAudioTrack`/`SetSubtitleTrack`; device click highlights only for now (routing lands with the renderer swap) |
| Bottom bar | Seekable timeline (drag→seek), VP (S4)/Media/Audio buttons, keyboard hints | `WM_LBUTTONDOWN` scrub → `Seek(g_dragTarget)` on release; Space/O/A/Esc/←/→/Enter |
| Demo defaults | ML **ON**, Tone **Auto**, Chroma **Default**, Detail **Off**, all Tone/Chroma options enabled | Forced in main, then pushed; deliberately ignores MPCVR's persisted state |
| Open-file default | Media filter picker, owned by `S3Main` | `PostMessage(WM_APP, kCmdOpen)` auto-posted at startup when no CLI file |

**Row widgets (3 control types, exactly — Unplugged rule):**
- **Toggle** — small switch in the control column: filled accent + black `ON`
  when on; dark fill + border + grey `OFF` when off.
- **Cycle** — `‹  Auto  ›` (`\u3008…\u3009`) in accent-light; click steps to the
  next option.
- **Slider** — track band with accent fill to the knob + `#FF8A4C` knob(12 px);
  min/max legend under the band ends (`0.00` … `1.50`); value readout right-aligned

- **States**: a row is either `disabled` (everything grey — master Enable off /
  group mode Off), or `adjustable` (draggable — control on AND section Manual).

## 7. AVR bitstream — decision trail (still in flight)

The crucial part: **HD-audio to the receiver, no PCM**.

- **The mpc-hc method (your research):** two knobs — audio renderer
  (MpcAudioRenderer, WASAPI **exclusive bitstream**) + decoder (LAV Audio
  `ILAVAudioSettings::SetBitstreamConfig(AC3/DTS/EAC3/TrueHD/DTSHD)` +
  `SetDTSHDFraming`).
- **Engine attempt that exploded:** compiling `MpcAudioRenderer.cpp` inside
  `mpchc_engine` — MFC/ATL vs BaseClasses `__POSITION` war, `Filters.h` app
  drag, `CString`/`POSITION` collisions, MT/MD runtime mismatch. **Decided:**
  standalone registered **`MpcAudioRenderer.ax`** wrapper.
- **`tools/mpc_audio_ax/`:** `audio_register.cpp` (minimal `CFactoryTemplate` +
  `DllRegisterServer`/`DllUnregisterServer` via `AMovieDllRegisterServer2`);
  `MpcAudioRenderer.def` exports the four entry points.
- **Current blocker (diagnosed, not yet fixed):** build fails with ATL/BaseClasses
  `__POSITION` redefinition — `BaseClasses/wxlist.h` only defines its own
  `__POSITION` when `__AFX_H__` is absent, so **MFC must precede `streams.h` in
  every TU**. Other findings: `Filters.h`/`CFilterApp` live only under
  `#ifdef REGISTER_FILTER` (keep it undefined); **prebuilt libs already exist**
  in `bin\lib\Release_x64` (`MpcAudioRenderer.lib`, `DSUtil`, `AudioTools`,
  `bs2b`, `soxr`, `ffmpeg`); the property-page header drags the whole mpc-hc
  theme (`CMPCTheme*`) which bitstream doesn't need.
