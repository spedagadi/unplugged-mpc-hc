## 3. Decided design (locked)

- **Form factor B** — one window; panels overlay the video (video never resizes);
  Up toggles WATCH ⇄ EDIT.
- **Engine = mpc-hc in place** — thin `mpchc_engine` seam, no clean-room engine,
  no `FGManager` lift.
- **Audio = reuse MpcAudioRenderer** (registered `.ax`); bitstream = WASAPI
  exclusive + LAV passthrough; **defaults: Bitstream + all HD formats ON**
  (targets an AVR/HDMI; toggle back to PCM in the Playback→OUTPUT sheet).
- **Zion ML** — all models preloaded regardless of usage; no load/unload during
  playback; demo has no settings persistence.
- **Scope v1** — VP ingest + local media; no recording/network/disc menus.

## 4. Today's fixes & root causes (the gotchas)

1. **Playback tabs disappearing** — `PaintPlaySheet` cleared the whole panel
   (covering the tab bar drawn first). Fix: sheet background starts at `kTabH`.
2. **Audio devices "not enumerating" on the HTPC** — `RefreshPlaybackInfo()` only
   ran on the CLI-file startup path; the file-picker path never refreshed.
   Fix: `RenderSessionEntered()` (refresh + bridge-seed + demo defaults) on open.
3. **MpcAudioRenderer crashed on CoCreate** (AV, ctor + 0x46d):
   `CWinApp* pApp = AfxGetApp();` returned **NULL** in a bare COM DLL (mpc-hc
   uses `CFilterApp theApp`). Fix: minimal global `CWinApp` (`ax_app.cpp`);
   isolated with a `co_test.exe` + cdb backtrace.
4. **`regsvr32` recorded `regsvr32.exe` as InprocServer32** (module-path quirk in
   the baseclasses register helper). Fix: after registering, pin the path:
   `reg add HKLM\...\CLSID\{601D2A2B-9CDE-40bd-8650-0485E3522727}\InprocServer32 /ve /d "<dll>" /f`.
   The bundle's `register_all.cmd` does this.
5. **Auto-gamma frozen at 1.0 while shadow/highlight moved** — `discard(pred,
   1.0, 0.7, 1.3)` is a *config sanitizer* (out-of-range ⇒ default 1.0); applied
   to model output it neutralized any prediction outside 0.7–1.3 even though the
   model's trained range is 0.5–1.5. Fix: clamp to 0.5–1.5; stats now expose
   `scene: raw=` (pre-clamp) + a `gates:` line
   (`tone/gammaEnable/gammaModel/features/gammaPredict`).
6. **Bitstream burried below long subtitle lists** — made Bitstream + all HD
   formats the demo default (engine `audioMode_` + `BitstreamConfig` defaults,
   re-asserted in `ApplyDemoDefaults()`).

## 5. HTPC deploy bundle

`C:\Code\mpc-hc\s3_shell_htpc.zip` (≈18 MB; staging dir `s3_shell_htpc\` beside it).

- Extract to a **stable** path (registration is absolute; don't move folders
  after installing), e.g. `C:\htpc\s3_shell_htpc`.
- Run **`register_all.cmd`** (elevated): registers LAV, MPCVR-Zion, MpcAudioRenderer
  and pins its `InprocServer32`; verifies all 5 CLSIDs.
- Run `bin\s3_shell.exe`. Keys: Up = panels, Space = play/pause, ←/→ seek, O open,
  A audio, Esc exit.
- `mpcvr\` keeps the .ax + the three `.plxgb` models together (models load from
  the module dir). `mpcvr\Reset_Settings.cmd` clears MPCVR's registry state.
