
🎬 What is Unplugged?
====================
Projector technology has come a long way in the home theater space, but Dynamic Tone Mapping (DTM) and overall picture quality still have room to grow on displays above a three-figure price tag.

Unplugged is an active, open-source research experiment that runs on a Windows HTPC today. The core mission of the project is to prove a bigger point: that the computational complexity of DTM, an ML-driven color grade, and full media playback is low enough for a single modern 4K SoC to handle all three simultaneously on projector hardware. Unplugged is expected to run on off the shelf, easily procurable ARM based embedded hardware in near future as a useful reference.

🚀 Key Technical Features
===========================
The project is actively pushing the envelope across a few exciting frontiers:

🤖 Machine Learning Zion Grade: Three real-time XGBoost ML models analyze every incoming frame to predict exactly how a professional colorist would shape the tone curve for that specific scene. This collective inference drives the Zion Grade—making real-time shadow, mid-tone, and highlight tracking decisions per frame.
⚡ Fast Feature Extraction (SAT): The engine utilizes a Summed Area Table (SAT) computer-vision technique to achieve lightning-fast feature extraction at a minimal performance cost. This drives the downstream scene-adaptive behaviors, including active black-bar detection, peak analysis, and temporal frame stability.
🔬 Scene Segmentation (Early Stage / WIP): Real-time GPU based ONNX instance segmentation specifically targeting sky and skin regions is in early stage. The ultimate roadmap goal is to feed these structural masks back into the tone mapper to protect faces and preserve complex sky gradients under aggressive tone-mapping curves. Even in its early stage, it serves as an open reference pipeline for integrating custom ML inference into live video processing.

🛠 Functionality & Deployment
====================
Unplugged acts as a single-box solution combining external processing and native playback. The dynamic tone mapping functions cleanly across both HDR10 and Dolby Vision (DV) streams:
1. Media Player Mode: Decodes and maps container files natively from local storage.
2. Video Processor Mode: Direct real-time capture, processing, and tone mapping of signal from an external source player .

💻 Hardware Requirements
==================
To deploy Unplugged, an HTPC setup requires:
🖥 OS: Dedicated HTPC running Windows 10 or 11 (64-bit) [Tested on RTX4070].
🔌 Capture Hardware: A Blackmagic DeckLink Quad PCIe card. (Note: This capture card is strictly mandatory for real-time external Video Processor mode; native Media Player mode requires no capture hardware).
💾 Media Sources: Local MKV or MP4 files or an external source player outputting 4K HDR10/Dolby Vision.
🔒 HDCP Status: Unplugged requires an unencrypted HDMI input signal. In accordance with standard DeckLink hardware configurations, the incoming HDMI signal must be non-HDCP.

⚠ Important Driver Note: To comply fully with open-source licensing, Unplugged does not package Blackmagic's proprietary runtimes. Users must independently download and install the latest Desktop Video Runtime Drivers directly from the official Blackmagic Design Support Portal before executing processor mode.


🔮 Future Work
============
🍓 Standalone Hardware : Getting the Unplugged pipeline running entirely on an ARM based Single Board Computer featuring HDMI-In. Code-named Osiris, this standalone reference architecture is the realistic target — proving that high-end DTM and ML grading can happen right inside the projection chain without an an external HTPC.
⚙ COM Object Exposure: Exposing the core renderer engine as a COM object to easily plug directly into MPC-HC and other DirectX video player platforms.

🤝 Open Source & Contributions
========================

Unplugged stands proudly on the shoulders of giants. The project has built upon and extended exceptional codebases, including MPCVR, MPC-HC, Libavfilters, and future architecture elements of mpv.

Because these open-source projects made Unplugged possible, it is only fair to pay it forward. The source code is completely open: feel free to use it, stress-test it, break it, modify it, and share your advancements.

Quick config
=========
1. Press Up on keyboard will toggle display of Live status and Settings panels.
2. Convert to SDR ON
3. Set SDR Display Nits, Static nits(max), Display black (nits) to calibrated and measured values
4. User trim is available in HDR tab for exposure, shadow and contrast
5. Best to leave Zion tab settings to Auto where applicable.
6. Calibration LUT files can be loaded in Output --> Display Calibration
7. PNG screenshot feature in Output --> Save as PNG
